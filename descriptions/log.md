# Работа модуля log

## Тактирование, сброс и запуска
Тактирование по двум частотам
 - **sys_clk** - частота работы всей системы
 - **log_clk** - частота дискретизации АЦП подключенного к логарифмическому усилитель AD8310ARZ

Сброс в модуль приходит буфферизированный по тактовым частотам
 - **sys_rst_n** - сброс для частоты sys_clk
 - **log_rst_n** - сброс для частоты log_clk

 Запуск нового рабочего цикла (log_clk Clock Domain)
  - **i_log_sync** - сигнал запуска приходит на частоте log_clk

## Входные данные (log_clk Clock Domain)
 - input [9:0] **i_adc_data** - данные от АЦП размерность [9:0]

## Входные параметры (log_clk Clock Domain)
 - input [15:0] **i_n_samples** - количество накапливаемых значений от АЦП
 - input [7:0] **i_accum** - количество значений для прореживания сигналов (из i_accum преобразований АЦП надо получить одно методом в зависимости от i_accum_type)
 - input [3:0] **i_accum_type** - 1 - выбрать максимум, 2 - взять среднее
 - input [3:0] **i_trans_meth** - метод перевода входных данных [9:0] в данные для упаковки [7:0] 1 - сдвиг вправо, 2 - ограничение (если > 255, то 255)

## Запуск (log_clk Clock Domain)
Сигнал запуска накопления данных производится по i_log_sync

## Выходные данные и параметры (sys_clk Clock Domain)
 - output   [15:0]  **o_out_size** - количество слов в выходном буффере для передачи
 - output           **o_data_ready** - выходные данные готовы для передачи
 - output   [31:0]  **o_out_data** - выходные данные
 - output           **o_out_vld** - валидность входных данных
 - input            **i_out_rdy** - готовность принимающей стороны к приёму данных

## Логика работы и внутренняя организация модуля
В модуле организован двойной буффер (бабочка) из двухпортовой памяти, которая работает на двух частотах  sys_clk и log_clk, после прихода сигнала 
запуска i_log_sync данные от АЦП начинают перепаковываться в 32 битные слова и записываться в память, когда в памяти накапливается i_n_samples 
отсчётов АЦП, выставляются количество данных (в 32-х битных словах) и выдаётся сигнал готовности на чтение o_data_ready. Буффер перещёлкивается и 
при приходе нового запуска i_log_sync начинает заполнятся вторая часть пока первая считывается и т.д. Данные из памфти выдаются в порт o_out_data с 
сигналом валидности o_out_vld и по готовности принимающего модуля i_out_rdy.
