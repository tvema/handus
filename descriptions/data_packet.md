# Работа модуля data_packet

# Тактирование, запуск и сброс
- Тактирование модуля происходит на одной системной частоте sys_clk
- Сброс происходит по буфферизированному сигналу сброса sys_rst_n в домене частоты sys_clk
- запуск производится по сигналу i_sys_sync в домене частоты sys_clk

# Входные данные
Входные данные приходят по двум потоковым шинам
- Данные от модуля A-Scan (ascan)
    - i_ascan_data [31:0] - данные
    - i_ascan_vld - валидность данных
    - o_ascan_rdy - готовность к приёму данных
    - i_ascan_data_size [15:0] - количество 32-х битных слов которые модуль ascan передаст
    - i_ascan_data_ready - готовность модуля ascan к передаче нового блока данных размером (i_ascan_data_size)
- Данные от модуля Log-Scan (log)
    - i_log_data [31:0] - данные
    - i_log_vld - валидность данных
    - o_log_rdy - готовность к приёму данных
    - i_log_data_size [15:0] - количество 32-х битных слов которые модуль log передаст
    - i_log_data_ready - готовность модуля log к передаче нового блока данных размером (i_ascan_data_size)
